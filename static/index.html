Cursor Configuration

Open Cursor > Settings > Features > MCP. Add a new server and use this JSON configuration:

{
  "mcpServers": {
    "Orchestrator": {
      "command": "node",
      "args": ["@modelcontextprotocol/client-sse", "http://localhost:8000/mcp"],
      "env": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Antigravity Configuration

Add the following configuration to your Antigravity MCP settings file (`mcp_config.json`):

{
  "mcpServers": {
    "orchestrator": {
      "command": "node",
      "args": ["@modelcontextprotocol/client-sse", "http://localhost:8000/mcp"],
      "env": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Kiro Configuration

In Kiro, you can add an SSE MCP server directly via CLI or settings. Use this configuration:

{
  "orchestrator": {
    "type": "sse",
    "url": "http://localhost:8000/mcp",
    "headers": {
      "Authorization": "Bearer YOUR_TOKEN"
    }
  }
}

Claude Desktop Configuration

Edit your `claude_desktop_config.json` file to include the orchestrator:

{
  "mcpServers": {
    "shared_brain": {
      "command": "node",
      "args": ["@modelcontextprotocol/client-sse", "http://localhost:8000/mcp"],
      "env": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}
